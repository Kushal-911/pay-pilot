ABOUT THIS WORKBENCH

Honest by design

D
Demo mode

All payment IDs, provider outcomes, and transaction events are synthetic and simulated in your browser. No funds move; no PayPal API is called.

L
Live API mode

Connects to this PayPilot server's REST API. Provider actions use the configured PayPal Sandbox. AI investigations use configured model credentials or deterministic fallback.

This is an unauthenticated local development prototype. Don't connect real merchant data or production PayPal credentials.

PAYMENT RECOVERY

Safe investigation runbook

  1. Match the merchant order to its PayPal order and capture identifiers.
  2. If capture is unknown, do not retry. A timeout does not prove failure.
  3. Refresh PayPal state and inspect verified events, amount, currency, and correlation.
  4. Use Investigate for a read-only evidence summary. Treat hypotheses as unconfirmed.
  5. Capture only after PayPal reports buyer approval and the explicit capture action is enabled.
This prototype is local-only and has no merchant authentication or tenant isolation. Use Sandbox data only.
